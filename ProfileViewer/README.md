# Profile Cards

This mod overhauls the pause menu for multiplayer!

## Features:

- See people's steam icon! (People with a pure white icon might be a malicious modder!)
- See people's steam profile!
- Instantly send someone a friend request!

## IMPORTANT!!!

This mod mainly uses the steam overlay to see someone's profile and to add them.

> If you have this turned off, turn it on for all the features!

The profile picture will still work regardless.
